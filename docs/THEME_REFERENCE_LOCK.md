## Locked visual principles

1. Light mode uses warm cream/off-white surfaces with green brand accents and illustrated tropical foliage.
2. Dark mode uses deep forest-green / near-black surfaces while preserving vivid natural green foliage and readable light brand lettering.
3. The compact mark is a leaf-integrated FaceBai `F` identity, not a generic social-network icon.
4. Light and dark assets must be purpose-built/approved variants where required; do not fake theme conversion with destructive CSS filters.
5. Backgrounds are real generated illustration assets, not CSS-drawn banana leaves.
6. Approved logos/icons/backgrounds must not be redrawn from memory or loosely approximated.
7. Responsive cropping and positioning are allowed only when the underlying approved artwork remains unchanged.
8. The dashboard master design and this theme board are complementary authorities: the dashboard governs overall product composition; this board governs light/dark brand and asset treatment.

## Implementation rule

Before any FaceBai screen is considered visually qualified, it must be reviewed in both light and dark modes against this reference where that screen supports theming.

Any new logo, icon, background, or theme-specific derivative must either:

- be a deterministic technical derivative of an already approved source with no creative alteration; or
- be separately generated, owner-approved, and SHA-256 locked before production use.
